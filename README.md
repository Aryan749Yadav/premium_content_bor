# Premium Content Bot for Telegram

A secure bot for selling and protecting premium content on Telegram.

## Features
- Premium-only content access
- Private database channel for content storage
- Time-limited content delivery (3 hours)
- Button-based navigation system
- Admin controls for user management
- Menu import/export functionality
